# Voice Coach Studio - Final

Open `index.html` in Chrome or Edge.

Recommended:
- Use Chrome/Edge for live browser transcript.
- Allow microphone permission.
- Pick a template from Library.
- Click Start.
- Read the selected text.
- Wait 1–2 seconds.
- Click Stop.
- Copy the generated Voice Movement Report.

Project structure:
- index.html
- css/styles.css
- js/data.js
- js/storage.js
- js/audio.js
- js/speech.js
- js/reports.js
- js/ui.js
- js/app.js
